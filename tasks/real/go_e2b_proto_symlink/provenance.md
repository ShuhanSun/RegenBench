## Why it is suitable for RegenBench

At the base revision, `internal/gen/envd/filesystem/filesystem.pb.go` is checked in and explicitly generated by the repository's `make generate` workflow from `proto/envd/filesystem/filesystem.proto`.

A patch that modifies only the generated Go file can make the pre-regeneration verifier compile. Canonical regeneration from an unchanged `.proto` removes that manual edit, causing the same verifier to fail. A source-of-truth repair updates the `.proto` and regenerates the binding, so the verifier survives regeneration.

## Environment requirements

The upstream repository declares Go 1.25. Canonical regeneration runs `make generate`, which requires `buf`, `protoc-gen-go`, and `protoc-gen-connect-go` in `PATH`, as documented by the repository's `DEVELOPMENT.md`.
